Rules for the fix:
- Fix the cause, not the symptom. Do not silence a diagnostic by deleting the code that triggers it, by casting the type away, or by widening a signature until it compiles.

- Do not weaken the storage layout to make a query compile. If a query genuinely cannot be expressed against the current layout, say so explicitly instead of quietly changing the layout.

- Change as little as possible. A large rewrite hides which edit actually fixed the error.
